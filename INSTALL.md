# Установка навыка `end`

Навык ставится в проект — папку с кодом или документами, которую вы открываете в Codex. Эта папка и есть корень проекта.

1. На странице репозитория нажмите зелёную кнопку «Code», затем «Download ZIP» и распакуйте архив.
2. Скопируйте папку `.agents/skills/end/` в корень проекта с тем же путём. Имя `.agents` начинается с точки, поэтому macOS Finder её скрывает: нажмите Cmd+Shift+точка, и скрытые файлы появятся. В Проводнике Windows такие папки видны сразу.
3. Скопируйте три шаблона из `.agents/skills/end/assets/` (`SESSION_STATE.md`, `DECISIONS.md`, `TODO.md`) в папку `docs/` проекта. Нет папки — создайте. Такие файлы уже есть — не перезаписывайте их. Недостающий файл навык создаст из шаблона сам.
4. Допишите содержимое `AGENTS.fragment.md` в конец `AGENTS.md` в корне проекта. Нет файла — создайте. Codex читает `AGENTS.md` в начале каждого чата, поэтому новый чат узнает, что сначала надо прочитать файлы состояния.
5. Перезапустите Codex. В Codex CLI и IDE вызывайте навык сообщением `$end` или выбирайте в списке `/skills`. Если всё установлено, навык выдаст промпт для нового чата и закончит ответ строкой `SESSION READY FOR HANDOFF`.

## Необязательно: напоминание о заполнении контекста

Hook при каждом вашем сообщении примерно оценивает остаток контекста и напоминает, когда пора сжать чат через `/compact` или вызвать `$end`. Напоминание приходит на английском. Отдельно он предупреждает, если последний запрос к модели превысил 80 000 входных токенов.

1. Перенесите содержимое `.codex/hooks.example.json` в `.codex/hooks.json` проекта (нет файла — создайте).
2. Проверьте, что установлен Python 3.
3. Просмотрите и разрешите hook через `/hooks` в Codex CLI. Пока hook не разрешён, файл `hooks.json` ничего не запускает.

Чтобы не повторять одно и то же напоминание, hook хранит короткое состояние в `~/.codex/state/context-watch/` (или в `$CODEX_HOME/state/context-watch/`). Имена файлов там — хеши идентификатора сессии, текст запросов не сохраняется.

Hook читает запись сессии (transcript), а её внутренний формат может меняться. Поэтому оценка приблизительная, при сомнении он сообщает «неизвестно» и никогда не останавливает работу. Об остатке контекста надёжнее судить по `/status`.

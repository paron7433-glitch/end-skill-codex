# end — перенос работы в новый чат Codex без потерь

Длинная сессия с агентом тратит лимит: на каждом ходе агент заново учитывает весь накопленный контекст. Выгоднее начинать новый чат на границе этапа, но новый чат не помнит старый. Навык `end` решает это: перед переходом он записывает состояние работы в файлы проекта и выдаёт готовый промпт для нового чата.

## Что делает навык

Навык записывает в папку `docs/` проекта:

- где вы остановились и что уже сделано (`SESSION_STATE.md`);
- какие решения приняли и почему (`DECISIONS.md`);
- что осталось сделать (`TODO.md`);
- что пробовали и что не сработало, чтобы не повторять;
- один конкретный следующий шаг.

Потом выдаёт промпт для нового чата. Новый агент сверяет записанное с тем, что на самом деле лежит в проекте, и продолжает работу.

Без вашего разрешения навык ничего не сохраняет в Git, не отправляет изменения на GitHub и не останавливает запущенные процессы.

## Установка

Пять шагов, подробно — в [INSTALL.md](INSTALL.md). Как пользоваться каждый день — в [DAILY-USAGE.md](DAILY-USAGE.md).

## Где не сработает

- Веб-версия ChatGPT: навыку нужен доступ к файлам проекта.
- Проект без Git: навык не проверит изменённые файлы и отметит это состояние как неизвестное. Git в проекте есть, если в корне лежит скрытая папка `.git`.
- Необязательный hook с напоминаниями работает только в Codex и требует Python 3.

## Состав

| Путь | Что это |
|---|---|
| `.agents/skills/end/` | Сам навык: инструкция, шаблоны файлов состояния, политика контекста, скрипт hook |
| `.codex/hooks.example.json` | Пример подключения необязательного hook |
| `AGENTS.fragment.md` | Фрагмент для `AGENTS.md` проекта |
| `INSTALL.md` | Установка |
| `DAILY-USAGE.md` | Памятка на каждый день |
| `CODEX-CAPABILITIES.md` | Что в комплекте — функция Codex, а что — обходной путь |
